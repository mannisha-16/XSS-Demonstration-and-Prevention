This demonstration illustrates DOM-Based Cross-Site Scripting. Client-side JavaScript extracts untrusted data from the URL parameter ?message=... and inserts it directly into the webpage using the dangerous DOM execution sink innerHTML.

Explanation: DOM-Based XSS occurs when client-side JavaScript reads untrusted input (such as URL parameters or hash fragments) and passes it to an execution sink like innerHTML or document.write(). The attack executes entirely inside the victim's browser memory without requiring malicious payload reflection from the web server.
